Theme Design Guide

颜色、圆角、动效，
都收敛成令牌

宿主用一套 CSS 自定义属性（令牌）承载全部颜色、圆角与动效。主题分浅色与深色，状态写在 <html data-theme="light|dark"> 上；模块只引用令牌，切换主题时自动跟随，不需要写监听代码。

01三条原则

  • 只读令牌，不写色值。模块内不允许出现 #fff、#0A141F、rgba(...) 这类硬编码颜色。
  • 语义优先。用“文字二级、卡片表面、分隔线”这类语义令牌，而不是“浅灰、白、深蓝”。深色下同一令牌会自动换成对应色。
  • 不重定义宿主令牌。模块不得在自身作用域内改写 --mh-*，否则会污染整页。

02命名规则

范围规则示例
宿主令牌--mh-*，模块只能引用var(--mh-accent)
模块自有变量--<模块id>-*--notes-gap: 12px
模块样式类名.mh-<模块id> 作为根，内部类再加前缀.mh-notes-list
样式节点一个模块只注入一个 <style id="mh-<id>-style">mh-notes-style

03最小令牌集

下面这些足够覆盖绝大多数模块界面，颜色值在 /theme.css 中统一维护。

令牌用途
--mh-bg / --mh-bg-1..3页面背景与背景层级
--mh-text / -2 / -3正文、次级文字、弱提示文字
--mh-line / --mh-line-strong分隔线、边框、更重的边框
--mh-surface / --mh-card-a / --mh-card-b面板底色、卡片渐变两端
--mh-soft / --mh-hover按钮静止底、悬停底
--mh-glass-border / --mh-inset毛玻璃边框、顶部内高光
--mh-accent / -deep / -line / -soft强调色：填充、深色文字、边框、淡底
--mh-blue / --mh-amber第二强调色、警示色
--mh-scrim遮罩层（弹层、模态）
--mh-shadow / --mh-shadow-hi常规阴影、悬浮阴影
--mh-radius / --mh-radius-lg圆角
--mh-ease统一缓动函数
--mh-font-d / -b / -m标题、正文、等宽字体
--mh-code-bg / --mh-code-text代码块底色与文字
--mh-warn-text / -bg / -line警告提示三件套

04允许与禁止

允许禁止
颜色、背景、边框、阴影、圆角、字体全部引用令牌硬编码 #fff、#333、rgba(0,0,0,.5)
半透明叠加用 color-mix(in srgb, var(--mh-accent) 15%, transparent)假设页面一定是浅色，直接写白底黑字
强调色底上的文字用 var(--mh-bg)强调色底上用 #fff（深色下会糊成一片）
模块自有尺寸、间距、布局用固定值覆盖 :root 或重定义 --mh-*
需要 JS 取色时读 getComputedStyle 上的令牌把色值复制进 JS 常量后再用
对比度：正文与背景的对比度不得低于 4.5:1。真拿不准时，直接复用宿主现有的令牌组合（--mh-text 配 --mh-bg、--mh-bg 配 --mh-accent），不要再自创。

05样式注入约定

const CSS = `
.mh-notes {
  color: var(--mh-text);
  background: transparent;
}
.mh-notes-input {
  background: var(--mh-soft);
  border: 1px solid var(--mh-line);
  color: var(--mh-text);
  border-radius: var(--mh-radius);
}
.mh-notes-input::placeholder { color: var(--mh-text-3); }
.mh-notes-input:focus {
  outline: none;
  border-color: var(--mh-accent-line);
  background: var(--mh-surface);
}
.mh-notes-btn {
  background: var(--mh-text);
  color: var(--mh-bg);
  border: 0;
  border-radius: 999px;
  transition: background .3s, transform .35s var(--mh-ease);
}
.mh-notes-btn:hover { transform: translateY(-1px); }
.mh-notes-item { border-bottom: 1px solid var(--mh-line); }
.mh-notes-warn {
  color: var(--mh-warn-text);
  background: var(--mh-warn-bg);
  border: 1px solid var(--mh-warn-line);
}
`;

function injectStyle(id, css) {
  const tag = 'mh-' + id + '-style';
  if (document.getElementById(tag)) return;
  const el = document.createElement('style');
  el.id = tag;
  el.textContent = css;
  document.head.appendChild(el);
}

export function mount(el, api) {
  injectStyle(api.id, CSS);
  el.innerHTML = `<div class="mh-notes">…</div>`;
  return () => { el.innerHTML = ''; };
}

模块面板的容器已经由宿主给出背景与圆角，模块根节点保持 transparent 即可，不要再套一层实色底。

06需要 JS 感知切换时

纯 CSS 场景不需要做任何事：令牌变了，样式自动重算。只有当你要把颜色画进 Canvas、图表库或内联 SVG 时，才监听主题事件。

const onTheme = (e) => drawChart(e.detail.theme); // 'light' | 'dark'
window.addEventListener('mh:theme', onTheme);
onTheme({ detail: { theme: document.documentElement.dataset.theme } });

// 卸载时记得移除
return () => window.removeEventListener('mh:theme', onTheme);

也可以直接读当前值：window.MicaTheme.get()、window.MicaTheme.toggle()。偏好存在 localStorage['mica.theme']，首次访问跟随系统 prefers-color-scheme。

07自检清单

  • 模块目录里搜索 #[0-9a-fA-F]{3,8} 与 rgba(，结果应为零（SVG 图标用 currentColor）。
  • 浅色与深色各看一遍：文字不消失、边框不消失、图标看得清、阴影不过分。
  • 强调色按钮上的文字用的是 var(--mh-bg)，不是 #fff。
  • 没有在模块内定义或覆盖 --mh-*。
  • 样式只注入一次，重复打开面板不会叠加 <style>。
  • 卸载函数里清理了 mh:theme 监听与定时器。

08验证方法

  • 点宿主顶栏的主题按钮切换，确认模块面板即时跟随，无需刷新。
  • 切到深色后刷新页面，确认偏好被记住（mica.theme）。
  • 清掉 mica.theme 后，DevTools 里把 prefers-color-scheme 设为 dark，确认首次访问即深色。
  • 切主题时打开控制台，确认没有样式或脚本报错。
